01 · Foundations

Distance Measures

A distance measure is a function d(x, y) that tells us how far apart two points are in a space.

1
Non-negativity

d(x, y) ≥ 0

2
Identity

d(x, y) = 0 if and only if x = y

3
Symmetry

d(x, y) = d(y, x)

4
Triangle inequality

d(x, y) ≤ d(x, z) + d(z, y)

L₂

Euclidean Distance

The ordinary straight-line distance between two vectors.

\[ d(\mathbf{x},\mathbf{y}) = \sqrt{\sum_{i=1}^{n}(x_i-y_i)^2} \]

Example:
a = (1, 2), b = (4, 6)
d(a,b) = √(3² + 4²) = 5

J

Jaccard Distance

Useful when comparing sets.

\[ d_J(A,B) = 1-\frac{|A\cap B|}{|A\cup B|} \]

A = {1,2,3}
B = {2,3,4}
Jaccard distance = 1 − 2/4 = 0.5

θ

Cosine Distance

Measures the difference in direction between vectors.

\[ d_{\cos}(\mathbf{x},\mathbf{y}) = 1- \frac{\mathbf{x}\cdot\mathbf{y}} {\|\mathbf{x}\|\|\mathbf{y}\|} \]

Same direction → distance 0.
Perpendicular → distance 1.

ED

Edit Distance

Minimum number of insertions, deletions, and substitutions needed to transform one string into another.

\[ D(i,j)= \begin{cases} i, & j=0\\ j, & i=0\\ \min \begin{cases} D(i-1,j)+1\\ D(i,j-1)+1\\ D(i-1,j-1)+[x_i\neq y_j] \end{cases}, & \text{otherwise} \end{cases} \]

d("cat","cut") = 1 Only one substitution is required: a → u.

H

Hamming Distance

Counts positions where two equal-length strings differ.

\[ d_H(\mathbf{x},\mathbf{y}) = \sum_{i=1}^{n} \mathbf{1}[x_i\neq y_i] \]

101101 vs 100001
Hamming distance = 2

02 · Cosine Similarity

LSH for Cosine Distance

Random Hyperplane LSH, commonly used in SimHash, converts the position of a vector relative to a random hyperplane into a binary hash value.

Random Hyperplane LSH

Choose a random vector \(\mathbf{r}\), which is the normal vector of the hyperplane. The hyperplane is defined by:

\[ \mathbf{r}^{\top}\mathbf{x}=0 \]

The hash is determined by which side of the hyperplane the vector \(\mathbf{x}\) lies on:

\[ h_{\mathbf r}(\mathbf x) = \operatorname{sign} \left(\mathbf r^{\top}\mathbf x\right) = \begin{cases} +1, & \mathbf r^{\top}\mathbf x \geq 0 \\[4pt] -1, & \mathbf r^{\top}\mathbf x < 0 \end{cases} \]

Thus, the dot product with the normal vector determines the side of the hyperplane.

Every time you add a hyperplane, each point receives a binary hash value depending on which side of the hyperplane it lies.

Why does this work?

Vectors pointing in similar directions are likely to fall on the same side of a random hyperplane. Therefore they are likely to receive the same hash bit.

03 · Binary Vectors

LSH for Hamming Distance

For binary vectors, a simple LSH strategy is to randomly select a bit position and use that bit as the hash value.

Random Bit Sampling

Consider these binary vectors:

10110110 -
10100110 -
10000110 -
11100101 -

At each step, LSH randomly chooses one bit position. Vectors having the same value at that position fall into the same bucket.

Select Next Bit to begin the animation.

Why random bits?

Two binary vectors that differ in only a few positions have a high probability of agreeing on a randomly selected bit.

Key idea

h(x) = xᵢ

Pick a random coordinate i and use its binary value as the hash.
