Slide: What is software engineering
Software and Engineering

Engineering: Engineering is the practice of systematically applying natural science and mathematics to design and improve systems, devices, or processes that solve problems under constraints. Wikipedia

Software: Software is a set of instructions and documentation that tells a computer what to do or how to perform a task. Wikipedia


Software: 
Application software e.g. facebook, word processor, food delivery app.
System software e.g. firmware, word processor, food delivery app.


Software engineering is an engineering discipline that is concerned
with all aspects of software production from initial conception to
operation and maintenance.

Myths of Software Engineering:

Software engineering is only coding. 

We dont need software engineering because of AI. Software engineering fundamentals matter more than ever now. As we add more features, codebase grows and chaos increases. Software engineering fundamentals is required on organize the complexity. AI models depends on input. Complex input more hallucination.

Software engineering is only prompt engineering. We have to steer the agents. We have to think long term.

We dont need software engineers because of AI agents: AI agents have short term memory. Their context is limited to certain number of tokens. 

Software is just a program: Software is not just a program or programs but also includes all electronic documentation that
is needed by system users, quality assurance staff, and developers.

Software engineering is required by Software Engineers only: it is required by AI engineers, data engineers.
